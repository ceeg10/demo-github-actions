# Postman API Testing

Colección de pruebas de API desarrollada con **Postman**.

## Archivos

* `Testing_API.postman_collection.json` — Colección de requests y pruebas.
* `Entorno_Local.postman_environment.json` — Variables de entorno utilizadas por la colección.

## Uso

1. Importar la colección en Postman.
2. Importar el Environment.
3. Seleccionar el Environment.
4. Ejecutar la colección desde **Collection Runner**.
